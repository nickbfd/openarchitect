# OpenArchitect

OpenArchitect is a free, open source residential design application: a 2D plan editor and a live 3D editor working on one building model, separate plan and layout files, and vertical (gravity) structural load calculations with beam and header recommendations.

It targets Windows and Linux as first-class platforms; macOS is built in CI.
